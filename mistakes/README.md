# Mistake Records

記錄會影響口試的核心錯誤與修正後的 mental model，讓後續重測有明確目標。目前尚未作答，因此沒有已記錄錯誤；不預設哪些主題弱。

## What to record

- 錯誤定義、必要假設遺漏、推導錯誤、complexity 錯誤、邊界 / ownership bug。
- 教授追問後才暴露的漏洞，即使首次回答看起來正確也要記錄。
- 單純語言不流暢與概念錯誤分開；正確內容不因口條差自動評 D。

## Workflow

1. 在 [mistake log](mistake-log.md) 加入真實紀錄，連到原始 session 題目 / 回答。
2. Core Mistake 用一句話指出最關鍵錯誤，不抄整段教科書。
3. Correct Mental Model 說明正確機制、條件或公式，加入一個能區分兩者的小例子。
4. 保留教授 follow-up，另安排變形重測與實際 Review Date。
5. 依 [spaced repetition](../review/spaced-repetition.md) 更新 Open / Reviewing / Resolved；原始錯誤不刪除。

Resolved 需兩次延後獨立重測達 A 並能處理變形；教學後立刻答對只記 assisted improvement。
