# School-specific Interview Preparation

只有在**已確定要口試，或一階通過**後，才投入大量 school-specific preparation。前期以 fundamentals、真實 portfolio evidence 與診斷為主，不讓猜題搶走基礎訓練時間。

目前沒有已確認的學校 / 系所、口試通知或 faculty targets，不建立虛構學校紀錄。

## 使用方式

1. 目標確定後，複製 [school template](school-template.md) 建立一所學校 / 一個 program 的文件。
2. 從系所 / 招生單位的 official information 核對 date、format、requirements 與 source，記錄 checked date。未公告或未確認填 UNKNOWN。
3. 寫具體 research fit、自己的背景如何接上、缺口與為何適合在這裡補足。
4. 查核 2–3 位 faculty 的現職、lab 與方向，每位至少讀一篇 paper / project，再寫 fit 與一個有資訊價值的問題。
5. 用實際 [portfolio](../research-defense/portfolio-index.md) 與 [defense templates](../research-defense/README.md) 準備研究方向、貢獻與 risk questions。
6. 將已查核的情境帶入 [mock](../mock-interviews/README.md)，更新 [Progress](../PROGRESS.md)，不要把查資料記成 Diagnostic 作答。

## Evidence and effort rules

- Official interview information、faculty page、paper / project 要各自有 source 與 checked date，注意年度與組別。
- Research direction、名額、錄取或面試形式不可由往年 / 非官方傳聞直接推定；無法確認就保留 UNKNOWN。
- 「師資優良」「資源豐富」「學術風氣好」不足以說明 fit；要回到具體研究問題與訓練需求。
- Faculty fit 的 shortlist 是準備候選，不代表已獲指導承諾；也準備主要老師無名額時的替代方向。
- 第 4 週可提高投入，但觸發條件未成立時，時間仍留給 full mock、defense 與 [spaced repetition](../review/spaced-repetition.md)。
